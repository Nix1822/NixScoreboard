# NixScoreboard

A sidebar scoreboard that updates every second.

- Title and lines set in `config.yml`
- Placeholders: `%player%`, `%online%`, `%max%`, `%ping%`
- `&` color codes supported
- `/nixscoreboard reload` (permission `nixscoreboard.admin`)

Build: `mvn clean package` -> `target/NixScoreboard-1.0.0.jar`
Requires Java 21 and Paper 1.21.4.
